# Projeto TaskFlow

API de gerenciamento de tarefas desenvolvida com **Python**, **FastAPI** e **SQLite**.

## Sobre o projeto

O TaskFlow é uma aplicação backend criada para praticar desenvolvimento de APIs REST com Python.  
O sistema permite cadastrar usuários, realizar login e gerenciar tarefas com operações completas de CRUD.

## Funcionalidades

- Cadastro de usuário
- Login com autenticação por token
- Criação de tarefas
- Listagem de tarefas
- Atualização de tarefas
- Exclusão de tarefas

## Tecnologias utilizadas

- Python
- FastAPI
- SQLite
- SQLAlchemy
- Pytest
- Swagger UI
- Git e GitHub
